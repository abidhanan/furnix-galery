# OD Furnix Galery

Katalog furnitur besi untuk cafe, restoran, dan hunian dari Jepara.

## Website

Production: https://furnix-galery.vercel.app

## Menjalankan Lokal

Proyek ini berupa situs statis berbasis React CDN dan dapat dijalankan dengan server HTTP lokal.

```powershell
python -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Struktur

- `index.html`: metadata dan entry point halaman.
- `src/components`: komponen antarmuka.
- `src/data`: informasi toko dan katalog produk.
- `src/styles`: gaya global.
- `assets/brand`: logo dan favicon.
- `assets/products`: gambar produk.
